# 本人进场分段

在局型旁新增独立的“本人进场分段”分组与筛选标签（`entry_rank`）。
使用战报的本人 `comp7Rank` 和定级赛标记；已有证据中 339 场分段全部匹配战前积分，
其中 88 场不匹配战后积分，所以不按战后积分重新分类。缺失分段保持未知。

顺序为传说、勇士、黄金 A–E、白银 A–E、青铜 A–E、黑铁 A–E、定级赛、未知。
选入该分组时默认选择“本人进场分段：高 → 低”，组合分组先比较本人分段再比较其它标签。
筛选值使用相同顺序；保留用户切换为结果指标排序的能力。
使用新键以保留旧 `self_rank` 保存视图迁移到局型的兼容行为。

验证：27 项 Explorer Python 检查通过；JavaScript 语法、分段交互、结果视图及 30% 情景检查通过。
分段交互检查覆盖全部级别、三个结果视图、组合分组、筛选、保存视图和切换标签。
开发预览使用已提交的历史快照，实际浏览器确认菜单项、默认降序和未知最后。
