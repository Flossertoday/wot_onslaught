# goal

The goal is to do a statistical analysis world of tanks onslaught mode replays. 

## game

The game installation is machine-local. Configure it with the first-run launcher,
`explorer.local.json`, `WOT_GAME_DIR`, or `--game`; no specific drive or install directory is required.
The currently verified replay format is World of Tanks CN Onslaught; compatibility
with other client regions and versions has not been established.
