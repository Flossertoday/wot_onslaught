# DOCS

`\DOCS` is where we put documents. There are four folders in `\DOCS`:

- `facts` holds facts that cannot be read from the codebase which doesn't fade away with time. 

- `status` holds progress. 

- `policy` holds our policies. 

- `logs` holds historical working logs. Name them  with date and short themes.
